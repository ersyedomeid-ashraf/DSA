Recursion -:

→ Recursion is a programming technique in which a function calls itself to solve a problem.

→ It helps in solving a problem by breaking it into smaller subproblems of the same type.

Important Parts of Recursion -:

Base Case
→ The condition that stops the recursive calls.
→ It prevents recursion from continuing infinitely.

Recursive Case
→ The part where a function calls itself to solve a smaller part of the problem.
