Sorting -:


→ Sorting is the process of arranging data in a specific order.

→ It arranges elements in ascending order or descending order.

→ Sorting makes data easier to understand and search.



Selection Sort -:


→ Selection Sort is a sorting algorithm that repeatedly finds the smallest element from the unsorted part of an array.

→ It places the smallest element at its correct position.

→ This process continues until the array is sorted.



Bubble Sort -:


→ Bubble Sort is a sorting algorithm that compares two adjacent elements.

→ If the first element is greater than the second element, they are swapped.

→ This process repeats until the array is sorted.

→ In each pass, the largest element moves to its correct position at the end.

Example:

[5, 3, 8, 2]

→ After sorting: [2, 3, 5, 8]
