Space Complexity -: 

→ It represents the amount of memory/space required by an algorithm.
→ It is expressed using Big-O notation.

Space Complexity = Auxiliary Space + Input Space

1. Auxiliary Space
→ The extra space used by an algorithm to solve the problem.
→ It does not include the space used to store the input.

2. Input Space
→ The space required to store the input data given to the algorithm.


Types of Space Complexity -:


O(1) → Constant Space
Memory usage remains constant as input size increases.

O(n) → Linear Space
Memory usage increases linearly with input size.

O(n²) → Quadratic Space
Memory usage increases as n × n.


Example -:

x = 5
y = 10
z = 15

total = x + y + z           ((x, y, z) -> is a input space or (total) -> is a auxiliary space)
print(total)
