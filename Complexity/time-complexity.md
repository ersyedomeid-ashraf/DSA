Time Complexity -:  

- Time Complexity is a way to measure how the number of operations performed by an algorithm
changes as the input size increases.

- TC is a rate of icrease in time with respect to input size.

TC → Big-O Notation → O(Growth of operations)


Rules for calculating TC:

1. Always calculate TC in terms of worst case.
2. Avoid constant values.
3. Avoid lower-order terms.


Different types of TC Notation :- 

1. Big-O Notation - O()

Big-O describes the upper bound of an algorithm's growth. 

it is commonly used to describe the worst-case time complexity. 

Example :- O(n)

2. Theta Notation - Θ()

Theta describes the exact tight bound of an algorithm's growth.

Example : - Θ(n)

3. Omega Notation - Ω()

Omega describes the lower bound of an algorithm's growth.

It is commonly used to describe the best-case time complexity.

Example - Ω(1)
