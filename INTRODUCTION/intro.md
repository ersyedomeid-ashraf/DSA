DSA -  Introduction 

1- What is DSA?

DSA stands for Data Structures and Algorithms.

Data Structure - A data structure is a way of storing and organizing data so that
 it can be ised efficiently.

EXAMPLES - 

* Array

* Linked List

* Stack

* Queue

* Tree

* Graph


Algorithm - An algorithm is a step-by-step procedure to solve a problem.


In simple words:
Data Structure → How we store data
Algorithm → How we solve a problem
